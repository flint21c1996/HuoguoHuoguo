# 참고 게임 분석 - 경영/채집 게임 비교와 훠궈훠궈 방향 후보

> 대상: 기획 방향 · 마지막 갱신: 2026-11-23

## 역할

다음 구현(손님, 영업, 메뉴)을 정하기 전에 비슷한 장르 게임들이 같은 문제를 어떻게 풀었는지 정리한 기획 참고 문서다.
아직 확정된 기획이 아니다. "정해야 할 질문" 절의 결정이 나면 `Overview.md`의 설계 원칙으로 옮긴다.

- 링크는 각 게임의 Steam 상점 페이지다 (2026-11-23 확인).
- 게임 설명은 널리 알려진 일반적인 구조를 요약한 것이고, 세부 수치는 확인하지 않았다.
- 특정 게임을 따라 만들지 않는다. 장르의 재미 요소(손님 자동 방문, 배치 조합, 조합 개발 등)만 가져와 훠궈훠궈 식으로 바꾼다.

## 정해야 할 질문

### 사장님 역할
| 방식 | 예시 | 장점 | 단점 |
|---|---|---|---|
| 완전 간접 (배치, 고용, 개발) | 카이로소프트, 투 포인트 | 판을 짜고 지켜보는 재미, 손님이 주인공 | 사장님 캐릭터가 할 일이 적음 |
| 완전 직접 (손으로 일함) | 오버쿡, 문라이터 | 손맛, 몰입 | 가게가 커지면 버거움 |
| 섞음: 탐험은 직접, 가게는 간접 + 가끔 개입 | 데이브 더 다이버 (반쯤) | 두 파트의 맛이 다름 | 개입 지점을 잘 골라야 함 |

### 탐험 중 가게 시간
| 방식 | 예시 | 장점 | 단점 |
|---|---|---|---|
| 시간대를 나눔 (탐험 시간 → 영업 시간) | 데이브 더 다이버, 문라이터 | 가게를 비울 걱정이 없음, 하루 계획 | 동시에 굴러가는 긴장감은 없음 |
| 계속 흐름 (직원이 돌림) | 카이로소프트 | 늘 무언가 진행 중 | 탐험이 곧 가게 방치 |
| 시간 멈춤 | 다수의 캐주얼 게임 | 단순함 | 하루 감각이 약함 |

## 방향 후보 (추천안, 미확정)

### 형태
- 사장님 역할은 "섞음": 탐험은 직접(지금 구현), 가게는 간접(배치, 메뉴 개발, 직원) + 가끔 개입(VIP 응대, 육수 급히 채우기 등).
- 하루를 시간대로 나눔: 낮 = 접근 행성 다이빙, 밤 = 영업. `OrbitCycle`이 하루가 되고, 행성의 "몇 시간 후 이탈"이 하루 계획의 압박이 된다.
- 훠궈 방식: 사장님은 요리를 완성해 내지 않는다. 꼬치를 준비하고, 손님이 테이블 냄비에 직접 담가 먹고, 먹은 꼬치 막대 수로 계산한다.

### 데이브 더 다이버와의 차별점
- 영업을 서빙 액션이 아니라 카이로소프트식 "판 짜기 + 손님 관찰"로 한다.
- 꼬치를 손님이 직접 담가 먹는 훠궈 방식, 외계인 종족 취향, 배치 조합 보너스.

### 핵심 반복
접근 행성 확인 → 다이빙해서 재료 사냥 → 영업 중 손님 반응 관찰 → 하루 끝 정산 → 메뉴 개발, 배치 개선 → 다음 날.

### 구현 순서 후보
1. 하루 시간대(낮 다이빙 / 밤 영업)와 하루 끝 정산
2. 손님: 에어록 입장 → 빈 의자 → 꼬치 먹기 → 말풍선 → 막대 수로 계산
3. 배치 조합 보너스
4. 메뉴 조합 개발 (재료 × 육수)
5. 직원

## 고른 시스템 (2026-11-23 사용자 선택)

여러 게임의 재미 요소를 훠궈훠궈만의 재료(테이블 냄비, 매일 바뀌는 절차적 행성, 외계인 종족)로 엮은 후보 중 사용자가 고른 것이다.

### 궤도가 손님을 데려온다
- 접근 중인 행성들이 그날 밤 손님 종족 구성을 정한다 (얼음 행성이 가까우면 얼음 종족이 많이 온다).
- 다이빙할 행성 고르기 = 그날 밤 장사 준비. 손님 고향 행성의 재료를 내면 "고향의 맛" 보너스.
- 기반: `UHGGameInstance`의 접근 행성 목록에서 손님 구성을 뽑는다.

### 손님이 메뉴를 발명한다
- 메뉴 연구 화면 대신, 손님이 가끔 엉뚱한 조합으로 담가 먹다가 새 메뉴를 만든다. 사장님이 그 장면을 보면 메뉴가 해금된다.
- 여러 종족을 받을수록 발명이 다양해진다. "지켜보는" 시간이 발견의 시간이 된다.

### 김으로 읽는 가게
- 말풍선 대신 냄비 김의 색과 모양이 테이블 상태를 보여 준다 (빨강 = 너무 매움, 거의 없음 = 식음, 하트 = 대만족 등).
- 아이소 시점에서 가게 전체의 문제 테이블이 한눈에 보인다. UI를 덜 쓴다.

### 정거장 환경 구역
- 정거장 안에 저중력, 추위, 옅은 산소 같은 구역이 있고 종족마다 편한 구역이 다르다.
- 가구 배치(구현됨)가 꾸미기가 아니라 환경 설계가 된다.

### 손님이 주는 정보 (사용자 제안)
- 종족 호감도: 종족별 만족 횟수가 쌓여 단골 단계가 오르고, 단계마다 정보를 준다.
  - 새 군계 행성 소문 → 그 군계 행성이 접근 목록에 나오기 시작.
  - 새 재료 소문 → 행성에 그 재료가 보이기 시작 (듣기 전에는 안 보이거나 정체불명 표식).
- 이름 있는 단골을 아주 크게 만족시키면 특별한 행성 좌표 → 다음 궤도에 전설 재료 행성 접근.
- 해금이 돈이나 등급이 아니라 손님과의 관계에서 나오는 정보라는 점이 차별점이다.

### 전체 순환
궤도 → 손님 종족 → 환경 구역에 자리 마련 → 김으로 보고 고침 → 손님 발명 메뉴 → 만족한 종족이 새 행성/재료 정보 → 그 정보로 다이빙 → 새 재료와 새 손님 → 다시 궤도.
탐험은 경영의 재료를 대고, 경영은 탐험의 지도를 넓힌다. 한쪽만 해서는 앞으로 못 나간다.

### 뺀 것
- 합석 냄비(손님끼리 국물을 이어 먹으며 맛이 변함): 국물 재활용이 위생상 꺼려진다는 이유로 제외. 냄비는 테이블(손님 무리)마다 새 국물이고 손님이 육수를 고른다.
- 맵기 단계 도박: 이번 선택에 들지 않음 (나중에 다시 볼 수 있음).
