# PlanetMaker - 절차적 행성 만들기 창

> 경로: `Source/HuoguoHuoguoEditor/Private/PlanetMaker/` · 마지막 갱신: 2026-11-27

## 역할

절차적 행성의 크기, 높낮이, 지형 모양(언덕, 능선, 잔 굴곡, 크레이터, 착륙지)을 에디터에서 직접 바꿔 보며 미리보고, 마음에 드는 값을 JSON으로 저장한다.
기획(행성이 어떤 모양이어야 하는지)은 사람이 에디터에서 정하고, 코드는 그 값을 읽기만 한다.

## 여는 법

1. 메뉴 **툴 → 훠궈훠궈 → Planet Maker** (또는 콘솔 `hg.PlanetMaker`, 실행 인자 `-ExecCmds="hg.PlanetMaker"`도 된다. 메인 창이 뜰 때까지 기다렸다 연다).
2. 창의 **미리보기 맵 열기** → `Maps/Development/L_PlanetMaker`가 열리고 카메라가 행성을 비춘다.
   다른 맵이라도 행성 생성기(`AHGPlanetGenerator`)가 있으면 그것을 쓴다.
3. 창은 처음에 따로 떠 있는 창으로 열린다. 탭을 끌어 에디터 안에 붙일 수 있다.

## 화면

| 부분 | 하는 일 |
|---|---|
| 탭: 소형 / 중형 / 평지 (대형) / 소행성 지대 / 폐우주선 | 환경 종류. 탭마다 만지던 값을 따로 들고 있다 (탭을 오가도 안 사라짐, 창을 닫으면 사라짐 → 저장할 것) |
| 주사위 (시드만 새로) | 다른 값은 두고 시드만 바꾼다. 언덕 위치와 크레이터 자리가 바뀐다 |
| 기본값으로 | 이 탭을 처음 값(그 환경이 나오는 첫 시드 + 기본 지형 모양)으로 |
| 미리보기 맵 열기 | `L_PlanetMaker`를 연다 (평지 탭이면 평지 맵 `L_Planet_Large`). 바뀐 맵이 있으면 저장할지 먼저 묻는다 |
| 랜드스케이프에 넣기 (평지 탭에만) | 분지 값으로 지금 맵의 랜드스케이프를 새로 만든다. 있던 랜드스케이프는 지운다 (먼저 묻는다, Ctrl+Z 가능). KillZ와 생성기 평지 설정도 맞춘다 |
| 행성으로 카메라 | 에디터 뷰포트 카메라를 행성 전체가 보이게 옮긴다 |
| 상태 한 줄 | 생성기를 찾았는지, 마지막 미리보기 결과(크레이터 수, 걸린 ms), 저장 경로 |
| 값 패널 | 행성 값(이름, 시드, 군계, 반지름, 높낮이, 언덕 촘촘함, 중력, 자원) + 지형 모양 값. 값 이름 위에 마우스를 올리면 설명이 나온다 |
| 불러오기... / 저장 / 저장 폴더 열기 | `Content/HG/Planets/<이름>.json`. 같은 이름이 있으면 덮어쓸지 묻는다. 불러오면 파일의 환경 종류 탭으로 옮겨 간다 |

- 값을 바꾸면 (슬라이더는 놓을 때, 숫자는 입력을 마칠 때) 생성기의 미리보기 지형을 다시 만든다. 소형 행성 약 50ms.
- 미리보기는 생성기 액터의 값(`PreviewPlanet`, `PreviewShape`)을 바꾸므로 맵이 "바뀜"이 된다. 미리보기 맵은 저장하지 않아도 된다 (JSON이 원본).
- 폐우주선 탭: 땅이 없어서 지형 미리보기가 비어 있다 (우주선은 고정형으로 만들 예정).
- 평지 (대형) 탭 (2026-11-27): 구가 아니라 랜드스케이프 분지다. 값 패널에 "평지 분지" 값(한 변 길이, 바닥/둑 비율, 둑 높이와 높낮이 변화, 바깥 낙차, 언덕)이 나오고, 구 지형 값은 숨는다.
  값을 바꿔도 자동으로 다시 만들지 않는다 (손본 땅이 사라지고 무겁다). **랜드스케이프에 넣기**를 눌러야 땅에 반영된다. 252m 분지 만들기 약 20ms.
  땅을 만든 뒤에는 랜드스케이프 도구로 원하는 곳만 손보면 된다. 자세한 규칙은 `Docs/Content/Maps.md`의 `L_Planet_Large`, `Docs/Source/Planet.md`의 평지 행성.

## JSON 파일

- `FHGPlanetPreset`을 그대로 JSON으로 쓴다 (`Docs/Source/Planet.md`). 키는 속성 이름(`radius`, `shape.craterCountMin` 등), 사람이 읽고 고칠 수 있다.
- `version`(지금 2, 평지 분지 값 `basin` 추가): 값 구성이 바뀌면 올린다. 더 새 버전 파일은 읽지 않는다. 옛 파일에 없는 값은 기본값으로 채운다.
- 게임은 아직 이 파일을 읽지 않는다. 고정 행성 목록으로 게임에 내보내는 것은 다음 단계 (그때 패키지에 `Content/HG/Planets`를 넣는 설정도 필요하다).

## 확인한 것 (2026-11-27)

- 에디터에서 창이 열리고 탭, 단추, 한국어 값 패널이 보인다 (에디터 창만 캡처해 확인).
- `L_PlanetMaker`를 열면 미리보기 지형이 생긴다 (로그 `[Preview] 지형 미리보기`, 57ms). 크레이터 개수를 20으로 바꾸면 다시 만들어진다.
- 자동화 시험 `HG.Planet.PresetJson`(저장/불러오기), `HG.Planet.TerrainShape`(기본 값이면 예전과 같은 지형).
- 평지: 파이썬에서 같은 함수(`unreal.HGPlanetMakerLibrary.apply_basin_to_landscape`)로 `L_Planet_Large` 땅을 만들어 확인 (게임 캡처까지). 창의 단추 자체는 손으로 눌러 보지 않았다.
- 아직 손으로 확인하지 않은 것: 불러오기/저장 파일 대화상자, 덮어쓰기 질문, 주사위와 탭 전환을 사람이 눌렀을 때의 흐름.

## 다음 할 일

- 손 조각(브러시): 지형을 직접 올리고 내린 획을 JSON에 목록으로 저장해 지형 위에 더한다.

- 고정 행성 목록: 저장한 JSON을 게임 다이빙 목록에 섞는다.
