# Shop - 경영 파트 (아이소 시점, 칸 배치와 콤보, 손님)

> 경로: `Source/HuoguoHuoguo/Shop/` · 마지막 갱신: 2026-11-24

## 역할

정거장 맵(L_Station)의 플레이. 가짜 아이소메트릭 카메라가 사장님을 따라가고, 사장님은 WASD로 가게 안을 걷는다.
B로 가구 배치 모드에 들어가 정해진 칸 위에 식탁, 의자, 장식을 놓고, 옮기고, 치운다 (카이로소프트식 칸 배치).
가구 종류는 데이터(Data/Furniture.csv, 엑셀로 열어 고침)가 정한다. 지금 19종: 냄비가 다른 식탁 6, 의자 5, 장식 8.
식탁 둘레에 무엇을 놓았는지에 따라 콤보가 생기고, 그 식탁 손님이 돈을 더 낸다.
낮과 밤에 손님이 들어와 식탁을 바라보는 의자에 앉아 꼬치를 먹고 계산하고 나간다.
접근 행성을 고르고 에어록 다이빙 발판을 밟으면 탐험 파트로 넘어간다.

## 파일

### HGShopGameMode (.h/.cpp)
- `PlayerControllerClass = AHGShopPlayerController`. L_Station의 World Settings에서 지정.

### HGShopBossCharacter (.h/.cpp)
`AHGBossCharacter` 상속. 경영용 사장님 + 아이소 카메라.
- 가짜 아이소메트릭: 원근 카메라 FOV 15도, 스프링 암 기본 5000 (2500~9000), `CameraPitch` -35도.
- 스프링 암은 `bUsePawnControlRotation`(컨트롤러 Yaw를 따름), 충돌 검사 끔(벽에 끌려 들어오면 시점이 깨짐).
- 위치 지연(`CameraLagSpeed` 6)과 회전 지연(`CameraRotationLagSpeed` 10): 따라가기와 회전이 부드럽다.
- `AddZoomInput`: 목표 암 길이를 비율(12%)로 바꾸고 Tick에서 보간.
- 걷기 속도 420 (탐험보다 느림, 좁은 가게라서).

### HGShopPlayerController (.h/.cpp)
`AHGPlayerControllerBase` 상속.
- 맵 시작: 도착 태그(`FromPlanet` 등)에 맞는 `AHGExplorerStart`에 경영용 사장님을 만든다. 카메라 처음 방향 = `AHGShopCameraAnchor`의 Yaw(없으면 시작점 Yaw).
- 조작 (`IMC_Shop`, 커서 보임, GameAndUI)
  - WASD: 사장님 이동. 카메라 Yaw 기준이라 W = 화면 위쪽. (`AHGBossCharacter::Move`)
  - 우클릭 드래그: 카메라 좌우 자유 회전. 우클릭을 누르는 동안만 마우스 X를 `AddYawInput`. 커서는 손님/UI 클릭용으로 남겨 둔다.
  - Q/E: 90도 회전 (`RotateStepDegrees`). 휠: 확대/축소. 숫자 1~4: 다이빙할 행성 선택. B: 가구 배치 모드.
  - T: 시간 넘기기 (`HGPassTime`, `IA_Shop_PassTime`, 평소 컨텍스트에만). 낮 → 밤 → 문 닫을 시간 → 하루 마치기(다음 날 낮, 새 행성 목록). 임시 조작이다 (나중에 "이 시간대 영업 마치기").
  - 조작 안내 줄 앞에 가진 돈을 쓴다 ("[경영] 가진 돈 107 | ..."). 손님이 계산할 때마다 다시 쓴다.
- 가구 배치 모드 (`IMC_ShopBuild`로 컨텍스트를 통째로 바꾼다. 이동/카메라 키는 같다)
  - 1/2/3: 분류(식탁/의자/장식) 고르기 (분류마다 마지막으로 골랐던 가구로). Z/C: 같은 분류 안에서 이전/다음 가구. 좌클릭: 놓기, 또는 가리킨 가구 집기. R: 90도 회전. X: 옮기기 취소 또는 가리킨 가구 치우기. B: 끝.
  - `PlayerTick`에서 매 프레임 `UHGFurniturePlacer::UpdateCursor`를 부른다. 조작 안내 첫 줄에 손에 든 가구 설명(`DescribeHeld`: "원앙 냄비 원탁 (식탁 2/6, 2x2, 값 180, 손님 +10%)"), 둘째 줄에 키, 셋째 줄(`>>`)에 콤보 미리보기를 쓴다. 미리보기가 바뀔 때만 다시 쓴다.
- 맵 시작 때 `CustomerDirector->Start(FurniturePlacer)`로 손님 흐름을 시작한다. 계산 메시지는 `ShowMessage`, 돈이 바뀌면 조작 안내를 다시 쓴다 (람다 콜백).
- `UpdateRotation`: 기본 처리 뒤 Pitch를 `CameraPitch`로, Roll을 0으로 되돌린다. 회전은 Z축 기준 Yaw만 남는다.
- 접근 행성 목록: 화면 고정 메시지(키 `0x48470002`), 고른 행성 앞에 `>>`. 첫 줄에 "N일째 낮/밤"과 "지금 내려가면 낮/밤 재료"를 쓴다. 문 닫을 시간이면 "오늘은 다이빙 끝. T로 하루를 마친다".
- 맵 시작 때 `FurniturePlacer->RestoreLayout()`으로 가구 배치를 되돌린다. 이동해 왔으면(행성에서 귀환) `GI->FinishDive()`로 시간대를 한 칸 넘기고("행성에서 돌아오니 1일째 밤이 되었다") 가방 내용을 메시지로 보여 준다 (`HGBag`).
- `EndPlay`: 접근 행성 목록 메시지(`0x48470002`)를 지운다. 지우지 않으면 행성 맵 화면에도 남았다.
- 개발 명령: `HGPlanets`, `HGSelectPlanet <번호>`, `HGDive [번호]`, `HGNextCycle`(다음 날 낮으로), `HGPassTime`(T와 같음), `HGRotate <도>`,
  `HGBuild`(배치 모드 전환), `HGBuildSelect <가구 ID>`, `HGBuildCategory <1~3>`, `HGFurnitureList`(가구 목록 전체 로그), `HGCursorAt <X> <Y>`(시험용 커서를 바닥 지점에), `HGCursorClear`, `HGFurniture`(배치 기록과 커서 상태, 미리보기 로그),
  `HGCustomers`(손님 상태, 돈, 발견한 콤보 수), `HGSpawnCustomer`(빈자리가 있으면 바로 한 명), `HGCombos`(식탁마다 자리 수와 콤보), `HGGiveIngredient <ID> <개수>`(가방에 재료 넣기).
- `DescribeForSimKey`: 카메라 Yaw/Pitch.

### HGFurnitureData.h

### HGFurniture (.h/.cpp)
모든 가구가 `AHGFurniture` 클래스 하나다. 무슨 가구인지는 `FurnitureId`(가구 데이터 행 이름)가 정한다.
- `OnConstruction`(에디터에 놓거나 옮길 때, 실행 중 스폰할 때): 행을 찾아 담고(`GetData`, 이름, 분류, 칸 크기, 보너스, 꼬리표), 부품을 지우고 다시 만든다 (`BuildParts`).
  - `FurnitureId`는 에디터 디테일 패널에서 행 이름 목록으로 고를 수 있다 (`GetOptions`).
  - 행이 없으면 1x1 회색 상자 + 경고 로그.
- 부품은 실행 중에 만드는 `UStaticMeshComponent`(엔진 기본 도형, 생성 스크립트 표시, 맵에 저장 안 됨). 크기는 칸 수에 맞춘다.
  - 식탁: `Round`(둥근 상판 78%, 가운데 다리, 받침) / `Square`(사각 상판, 네 다리). 냄비 `Single`(홍탕) / `YinYang`(홍탕·백탕 타원 둘 + 칸막이) / `NineGrid`(네모 냄비 + 가로세로 칸막이 두 줄씩) / `Big`(1.5배). 냄비 지름 = 짧은 변의 30%. 김(구 3개)은 숨겨 두었다가 손님이 먹을 때 켠다.
  - 의자(1x1, 앞쪽 +X): `Stool`(등받이 없음) / `Wood`(좌석 + 등받이 판) / `Cushion`(방석 + 높은 등받이) / `Arm`(네모 좌석, 방석, 등받이, 팔걸이).
  - 장식: `Bush`(토분 + 잎 덤불) / `Bamboo`(대 셋) / `Lantern`(기둥 + 둥근 등) / `PaperLantern`(틀에 매단 홍등, 금색 테) / `SauceBar`(바 + 소스 그릇 셋) / `Tank`(받침장 + 수조 + 물고기) / `Screen`(지그재그 병풍).
- 실제 가구는 충돌 부품이 `BlockAll`(사장님을 막음). 유령(`MakeGhost`, 스폰을 끝내기 전에 부르면 부품이 처음부터 유령 충돌로 만들어진다): `QueryOnly` + 모든 채널 Overlap + 겹침 이벤트 끔.
- `SetPreviewState`: None(원래 색) / Valid(초록) / Invalid(빨강) / Hover(주황). `SetSteam(bOn, Color)`: 식탁 김.
- `AHGTable`, `AHGChair`: 맵 에셋(L_Station)에 이미 놓인 옛 가구 액터의 클래스라서 남겨 둔다. 기본 ID(`Table`, `Chair`)만 다르다. 새로 쓰지 않는다.
### HGShopGrid (.h/.cpp)
가게 바닥 칸 규칙 `FHGShopGrid` (배치 컴포넌트의 `Grid` 속성).
- 칸 번호 = 월드 좌표 / `TileSize`(100) 내림. 칸 사각형 `FIntRect`는 Min 포함, Max 제외.
- 바닥 `FloorMin` (-6,-5) ~ `FloorMax` (6,5): L_Station 바닥 12m x 10m 전체. 손님이 걷는 범위.
- 배치 영역 `BuildMin` (-5,-5) ~ `BuildMax` (4,3): 월드 X -500 ~ 400, Y -500 ~ 300, 9 x 8칸. 서쪽 한 줄(입구 통로), 북쪽 주방, 동쪽 진열대 앞이 빠진다. 가게 키우기는 이 범위를 넓히면 된다.
- 손님 입구 `EntranceTile` (-6,-5): 남서쪽 구석.
- `CursorRect(Point, Size)`: 배치 커서용. 커서가 가리키는 칸이 가구의 첫 칸(Min)이 되고 +X, +Y로 크기만큼 뻗는다 (홀수 크기는 커서 칸이 가운데).
- `SnapRect(Point, Size)`: 가구 가운데가 지점에 가장 가까운 칸 사각형. 놓인 가구의 원점에서 칸을 거꾸로 구할 때와 맵 가구 맞추기에 쓴다 (`RectFromCenter`). `RotateSize`: 90/270도면 가로세로 바꿈.
- 2x2 식탁의 가운데는 칸 꼭짓점에, 1x1은 칸 가운데에, 2x1은 칸 변 가운데에 온다. 기준은 늘 "차지한 칸"이다.
- `Overlaps`(칸을 같이 씀), `Touches`(겹치지 않고 둘레 한 칸 안, 대각선 포함 → 콤보), `IsSideNeighbor`(상하좌우 바로 옆 → 의자 자동 방향).
- `HGShopGrid::GatherItems`: 맵의 실제 가구를 `FHGGridItem`(액터, ID, 분류, 꼬리표, 칸 사각형)으로 모은다. `GetFrontTile`: 가구 앞쪽(+X) 바로 앞 칸.

### HGShopCombos (.h/.cpp)
- `FHGComboRow`(DataTable 행, 원본 `Data/Combos.csv`): `DisplayName`, `Needs`(가구 ID나 꼬리표, `Plant+Light`, `Plant*3` 형식), `BonusPercent`. 행 이름이 콤보 ID.
- `HGCombo::CountAround(TableRect, Items)`: 식탁 둘레(Touches)에 걸친 가구를 ID별, 꼬리표별로 센다. `Evaluate`: Needs를 모두 채운 콤보를 표의 행 순서로 모으고 보너스를 더한다. `EvaluateTable`: 둘을 합친 것.
- `FHGComboResult::Describe`: "초록 쉼터 +20%, 등불 아래 +20%".

### HGFurniturePlacer (.h/.cpp)
경영 컨트롤러에 붙는 배치 모드 컴포넌트.
- 속성: `Grid`(`FHGShopGrid`), `RotateStepDegrees` 90.
- 가구 목록(`GetCatalog`): 가구 DataTable의 행 이름을 행 순서대로. 처음 부를 때 불러오고 표를 UPROPERTY로 잡아 둔다. `SelectCategory`(분류마다 마지막 가구 기억), `CycleInCategory`(Z/C), `SelectFurniture(ID)`.
- 가구는 ID로 만든다(`SpawnFurniture`): 행의 `ActorClass`(비면 `AHGFurniture`)를 미뤄서 스폰하고 `FurnitureId`를 정한 뒤 스폰을 끝낸다. 유령도 같은 길.
- 배치 모드에 들어가면 칸 판(1m 평면을 줄인 것)을 인스턴스 메시 세 장으로 깐다 (`ShowGridOverlay`). 충돌, 그림자 없음. 판끼리 깜빡이지 않게 층마다 높이가 다르다(0.6 / 1.0 / 1.4).
  - 배치 영역의 모든 칸 (청록). 판 사이 틈이 칸 무늬가 된다.
  - 놓인 가구가 차지한 칸 (짙은 남색, `RefreshOccupiedCells`). 가구마다 몇 칸을 쓰는지 바닥에 보인다. 놓기/집기/치우기/취소 때 다시 만든다.
  - 손에 든 가구가 차지할 칸 (초록 = 놓을 수 있음, 빨강 = 없음) 또는 가리킨 가구의 칸 (주황) (`SetHighlight`).
- 커서 → 바닥 칸: 마우스 화면 좌표를 `DeprojectScreenPositionToWorld`로 광선으로 바꾸고, 광선이 `Grid.FloorZ` 수평면과 만나는 점의 칸을 고른다.
  시험용 `SetCursorWorldOverride`는 월드 지점을 `ProjectWorldLocationToScreen`으로 화면 좌표로 바꾼 뒤 같은 경로를 탄다.
- 가리키기: 커서 칸을 차지한 가구가 있으면 Hover (주황 칸). 옮기는 중에는 보지 않는다.
  예전에는 가구 모양에 광선을 쏴서 판정했는데, 아이소 시점에서 앞쪽 식탁 윗부분이 뒤쪽 빈 칸을 가려 빈 칸을 가리켜도 식탁이 잡혔다. 칸 배치라서 "가리킨 칸"으로 판정한다.
- 빈 칸이면 `CursorRect`로 손에 든 가구가 차지할 칸을 정한다.
- 의자 자동 방향(`FaceTableYaw`): 지금 방향으로 이미 식탁을 보고 있으면 그대로, 아니면 상하좌우 바로 옆 식탁 가운데 쪽. 식탁 두 개 사이에서는 R로 어느 식탁을 볼지 고른다.
- `CheckPlacement(Candidate, Rect, Items)`
  1. 칸: 배치 영역 안이어야 하고("가구를 놓을 수 있는 칸 밖"), 다른 가구와 칸이 겹치면 안 된다("칸이 겹침: 식탁").
  2. 겹침: 유령의 충돌 부품마다 `UWorld::ComponentOverlapMulti`(바닥에서 2 띄움). 가구가 아닌 벽, 카운터, 사장님, 발판 트리거와 겹치면 불가.
- 콤보 미리보기(`GetPreviewText`): 유령을 놓았다고 치고 계산한다. 식탁이면 "이 자리: 초록 쉼터 +20%"(없으면 안내), 장식/의자면 맞닿는 식탁마다 놓기 전후를 비교해 "옆 식탁에 새 콤보: 등불 아래 +20%, 정원 등불석 +30%".
- 놓기: 놓은 가구가 닿는 식탁의 콤보 중 처음 만든 것을 `GI->DiscoverCombo`로 기록하고 "새 콤보 발견: 정원 등불석!"을 붙인다.
- 집기: 가구를 지우고 같은 종류/방향 유령을 든다. 원래 자리는 `MovingFrom`에 남겨 X나 배치 모드 끝, 다른 가구 고르기 때 되돌린다.
- 배치 기록: 놓기/치우기/취소 때 맵의 모든 실제 가구(클래스, 위치, Yaw)를 `UHGGameInstance::SetShopLayout`에 통째로 쓴다.
  `RestoreLayout`: 기록이 없으면(게임 켜고 처음) 맵의 가구를 칸에 맞춰 옮긴 뒤(`SnapMapFurnitureToGrid`, 맞출 수 없으면 치움) 기록, 있으면 맵의 가구를 치우고 기록대로 다시 놓는다.
  맵 에셋(L_Station)의 가구는 칸 배치 이전의 자유 좌표에 있다. 맵을 고치지 않고 실행할 때 맞춘다: 식탁 (-300,-250) → 칸 (-4,-3)~(-3,-2), 가운데 (-300,-200).

### HGCustomer (.h/.cpp)
- `AHGCustomer`: 손님 몸 (원통 몸통 + 구 머리, 몸 색 = 종족 자리 표시). 충돌 없음. 스스로 판단하지 않고 `WalkPath`(지점들을 차례로 걸음, 170cm/s, 걸을 때 통통 튐), `SitAt`(의자 위로 40 올라가 앉음), `StandUp`만 한다.
- `AHGMoneyPopup`: 계산할 때 식탁 위로 떠오르는 "+42" 글자(`UTextRenderComponent`). 1.6초 동안 올라가며 카메라를 보고, 마지막 0.4초에 작아져 사라진다. 엔진 기본 글꼴에 한글이 없어서 숫자만 쓴다.

### HGCustomerDirector (.h/.cpp)
경영 컨트롤러에 붙는 손님 흐름 컴포넌트 (첫 시제품).
- 들어오기: 영업 중(낮, 밤)이면 `ArrivalInterval`(7초)의 0.6 ~ 1.4배 간격으로 입구 칸에 손님이 나타난다. 문 닫을 시간에는 새 손님이 없고, 안에 있던 손님은 마저 먹고 나간다.
- 빈자리 = 식탁을 바라보는 의자(의자 앞 칸이 식탁, `GetFrontTile`) 중 다른 손님이 잡지 않은 것. 빈자리가 없으면 오지 않는다. 빈자리를 섞어 길이 있는 첫 자리로 보낸다.
- 길 찾기(`FindPath`): 바닥 칸 위 상하좌우 너비 우선 탐색. 가구 칸과 고정 장애물 칸(`StaticBlocked`)을 피한다. 출발 칸과 도착 칸(의자)은 가구가 있어도 지나간다.
  고정 장애물은 맵 시작에 칸마다 상자(칸 70%, 바닥 위 20~140)로 겹침 검사해서 찾는다. L_Station: 22칸 (TravelPad_Airlock, Counter, IngredientShelf).
- 먹기: 의자에 앉아 식탁을 보고 `EatSeconds`(10초). 그동안 식탁 김이 켜진다. 김 색 = 그 식탁 콤보 수 (없음 흰색, 1개 연한 금색, 2개 이상 진한 주황). 0.5초마다와 손님이 앉고 일어날 때 다시 칠한다.
- 계산(`Pay`): 꼬치 `SkewersPerCustomer`(3)개. 가방에서 재료를 하나씩 꺼내(`TakeOneFromBag`) 그 재료의 `Price`, 가방이 비면 기본 꼬치 `BasicSkewerPrice`(5).
  합계 × (100 + 식탁 보너스 + 앉은 의자 보너스 + 식탁 콤보 보너스 합) / 100, 반올림. 식탁/의자 보너스는 가구 데이터 `BonusPercent`. `GI->AddMoney`.
  메시지 "손님 계산 +29 (꼬치 기본 꼬치 3 = 15, 원목 원탁 +0%, 나무 의자 +5%, 콤보 초록 쉼터 +20%, 등불 아래 +20%, 정원 등불석 +30%, 행성 향기 +15%) | 가진 돈 61".
- 나가기: 입구 칸으로 걸어가 사라진다. 길이 막혔으면 입구로 곧게 걷는다 (충돌이 없어 갇히지 않는다).
- 앉을 의자나 식탁이 사라지면(배치 모드에서 집거나 치우면) 계산하지 않고 나간다.

## 흐름 / 규칙

- 회전은 Z축(좌우)만. 위아래 기울기를 풀면 아이소 시점의 "내려다보는 판" 느낌과 가림 규칙이 무너진다.
- 가구의 처음 배치는 맵(L_Station의 `Shop/Hall` 폴더 가구 액터)이 기준이다. 실행할 때 그 액터들의 ID와 자리만 읽고 지운 뒤, 데이터로 다시 만들어 가장 가까운 칸에 놓는다 (`ReplaceMapFurniture`).
- 가구 종류를 늘리거나 값, 색, 크기를 바꿀 때는 `Data/Furniture.csv`만 고친다 (`Docs/Content/Data.md`). 새 생김새 종류(Style)가 필요할 때만 `AHGFurniture::BuildParts`에 코드를 더한다.
- 가구끼리는 칸으로, 가구와 그 밖의 것(벽, 카운터, 사장님)은 충돌 모양으로 판정한다.
- 확인됨 (스모크 테스트): 카메라 Yaw 45에서 S → 이동 방향 -135, `HGRotate 90` 후 S → -45. W로 에어록 발판까지 걸어가 다이빙, 탐험 파트로 전환.
- 확인됨 (하루 구조, `HGSeq`): 1일째 낮 다이빙 → 귀환 "1일째 밤" → 같은 행성 다시 다이빙 → 귀환 "1일째 문 닫을 시간" → 다이빙 거절 → `HGPassTime` "2일째 낮", 새 행성 4개, 떠난 행성의 캔 기록 삭제.
- 확인됨 (사용자가 직접 플레이): 실제 T 키로 2일째 ~ 6일째까지 낮 → 밤 → 문 닫을 시간 → 다음 날이 반복되고 메시지가 맞게 나온다.
- 확인됨 (칸 배치와 콤보, `HGSeq` + `HGCursorAt` + `HGSimKey LeftMouseButton`으로 실제 입력 경로를 거침):
  - 맵 가구 8개를 칸에 맞춤(치운 것 0). 배치 모드에서 칸 무늬 표시(화면 캡처).
  - 식탁 1 왼쪽 칸 (-5,-3)에 화분: 미리보기 "옆 식탁에 새 콤보: 초록 쉼터 +20%" → 놓기 → "새 콤보 발견: 초록 쉼터!".
  - (-5,-2)에 등불: 미리보기 "등불 아래 +20%, 정원 등불석 +30%" → 놓기 → 두 콤보 발견. `HGCombos` "식탁 1 ... 보너스 70%".
  - 식탁 1 오른쪽 칸 (-2,-3)에 의자를 방향 0으로 들어도 방향 180(식탁 쪽)으로 놓임.
  - 카운터 쪽 (100, 380)은 "가구를 놓을 수 있는 칸 밖"으로 거부. 이미 있는 식탁을 가리키면 Hover.
  - 소스 바(2x1): 방향 0이면 칸 (2,-3)~(3,-3), R 한 번(90도)이면 칸 (2,-3)~(2,-2). 식탁 2 오른쪽에 놓아 "소스 장인석 +25%" 발견.
  - 식탁 칸을 가리키면 그 식탁 Hover(앞 식탁이 가려도 칸 기준). 빈 칸 (2,1)을 가리키면 식탁 유령이 칸 (2,1)~(3,2)를 차지하며 놓을 수 있음.
  - 화면 캡처: 놓인 가구 밑 짙은 칸(식탁 4칸, 의자 1칸, 소스 바 2칸)과 손에 든 식탁의 초록 4칸.
- 확인됨 (손님):
  - 손님이 입구에서 의자까지 4 ~ 11칸 걸어 앉고, 10초 뒤 계산하고 나감. 빈자리가 없으면 "빈자리가 없어서 손님이 들어오지 않았다".
  - `HGGiveIngredient GlowCap 4` 뒤 첫 손님 "꼬치 야광버섯 3 = 42", 다음 손님 "야광버섯 1, 기본 꼬치 2 = 24" (가방이 비면 기본 꼬치).
  - 콤보 식탁 손님 "+26 (기본 15, 보너스 70%)", 콤보 없는 식탁 "+15". 화면 캡처로 먹는 동안 김(흰색 / 콤보 식탁은 금색)과 "+26" 글자 확인.
  - 먹는 손님의 의자를 X로 치우면 "먹던 자리가 없어져서 손님이 계산하지 않고 나갔다".
  - 문 닫을 시간이 되면 새 손님 없음 ("영업 끝"), 먹던 손님은 계산하고 나감.
  - 화분을 놓고 다이빙 → 귀환: "기록에서 9개를 다시 놓음", 식탁 1 콤보 유지, 밤에도 손님이 다시 들어옴.
- 확인됨 (가구 데이터, `HGSeq`): 가구 목록 19종(식탁 6, 의자 5, 장식 8) 불러옴. 맵의 옛 가구 8개를 데이터로 다시 만들어 칸에 맞춤(놓지 못한 것 0).
  - 원앙 냄비 원탁, 팔걸이/방석 의자, 대나무, 홍등, 야광버섯 화분, 수조, 구궁격 사각탁, 둥근 의자, 우주 의자, 등불을 놓음. 화면 캡처로 생김새가 서로 다르게 보임 (구궁격 냄비의 9칸 칸막이 포함).
  - 꼬리표 콤보: 대나무(Plant) + 홍등(Light) + 야광버섯 화분(Plant, Planet) → 초록 쉼터, 등불 아래, 정원 등불석, 행성 향기, 보너스 85%. 수조(Water) → 물멍석. 우주 의자(Planet)를 식탁 옆에 놓으면 행성 향기.
  - 손님 계산에 의자 보너스가 들어감: "원목 원탁 +0%, 팔걸이 의자 +15%" → 15 × 1.15 = 17.
  - 같은 방향을 다른 가구에도 이어서 든다: 병풍(2x1)을 R로 돌리다가 옆 식탁과 칸이 겹쳐 "칸이 겹침: 원목 원탁"으로 거부됨 (정상).
- 확인 안 됨: 식탁 보너스(원앙 +10% 등)가 들어간 계산 (손님이 그 식탁에 앉기 전에 시험이 끝남, 의자 보너스와 같은 코드), 연회 대원탁(3x3)과 2인 사각탁(2x1) 배치, 엑셀로 저장한 CSV를 다시 읽어 들이기. 실제 마우스로 칸에 가구를 놓는 손맛과 미리보기 가독성, 실제 마우스 우클릭 드래그 회전 감도 (OS 입력을 넣지 않으므로 사람이 확인해야 한다). 손님이 많을 때 겹쳐 걷는 모습.

## 알려진 문제와 다음 할 일

- 가게 키우기(배치 영역 넓히기, 돈 쓰기)가 아직 없다. 가구 `Price`는 데이터에 있지만 아직 돈을 내고 사지 않는다. 돈은 쌓이기만 한다.
- 가구가 늘면 1/2/3 + Z/C로 고르기가 번거롭다. 정식 가구 목록 화면(UMG, 사진과 값)이 필요하다.
- 가구 생김새는 기본 도형 자리 표시다. 블루프린트 아트를 만들면 행의 `ActorClass`에 적는다 (그 블루프린트가 부품을 어떻게 다룰지는 그때 정한다).
- 손님 쪽 식탁 판정이 "식탁을 바라보는 1x1 의자"뿐이라, 2인 사각탁(2x1)은 긴 변 두 칸에 의자를 놓아야 두 명이 앉는다. 벤치(2x1 의자)는 아직 없다.
- 손님은 한 종류(색만 다름)이고 취향이 없다. 종족, 궤도가 데려오는 손님, 손님 도감은 다음 단계.
- 꼬치는 가방 재료를 표 순서로 자동으로 꺼낸다 (오늘의 꼬치판 고르기 등 꼬치 공급 방식은 미정).
- 손님끼리, 손님과 사장님은 서로 뚫고 지나간다 (충돌 없음). 같은 칸을 동시에 지나갈 수 있다.
- 금액 글자(`AHGMoneyPopup`)가 지정한 금색보다 흐리게(흰빛으로) 보인다. 글자 머티리얼을 아트 단계에서 바꾼다.
- 카메라를 돌리면 높은 벽이 사장님을 가린다. 벽 자동 낮추기(컷어웨이)가 필요하다.
- 가구 배치, 돈, 발견한 콤보는 게임이 켜져 있는 동안만 남는다 (저장 파일 없음).
- 배치 모드에서 유령은 단색(초록/빨강)이다. 반투명 머티리얼은 아트 단계에서 바꾼다.
- 맵 에셋의 처음 가구가 칸에 맞지 않은 자유 좌표의 옛 클래스(`AHGTable`/`AHGChair`) 액터다 (실행 때 데이터로 다시 만듦). 맵을 다시 다듬을 때 `AHGFurniture`로 바꾸고 칸 좌표에 놓으면 좋다.
- 한 번 관찰됨 (재현 안 됨): 행성에서 정거장으로 돌아온 지 1.3초 만에 사장님이 다이빙 발판에 닿아 다시 다이빙했다. 같은 순서로 5번 더 돌렸을 때는 나오지 않았다. 원인 확인을 위해 `RequestTravel` 로그에 사장님 위치와 맵 시작 후 시간을 남긴다.
- 행성 선택과 출항이 키 입력 + 발판이다. 정식 UI(레이더/출항 화면)로 바꿀 후보.
