# Planet - 행성 시드와 절차적 행성 생성기

> 경로: `Source/HuoguoHuoguo/Planet/` · 마지막 갱신: 2026-11-24

## 역할

행성은 맵 에셋이 아니라 시드 값으로 존재한다. 같은 시드면 언제나 같은 행성. 행성 표면 맵의 생성기가 시드로 구형 지형과 배치를 만든다.

## 파일

### HGPlanetTypes (.h/.cpp)
- `EHGPlanetBiome`: `Rock`(바위, 고추), `Ice`(얼음, 해초), `Fungal`(버섯숲, 버섯)
- `EHGPlanetSize`: `Small`(반지름 40~120m), `Medium`(300~600m)
- `FHGPlanetSeed`: `Seed`, `Name`, `Biome`, `SizeClass`, `Radius`(cm), `TerrainAmplitude`(반지름 대비 높낮이 비율), `TerrainFrequency`, `GravityScale`, `Richness`, `HoursLeft`(표시용). `Describe()`는 한 줄 설명.
- `HGPlanet::MakePlanet(Seed)`: `FRandomStream`으로 값을 뽑는다. 뽑는 순서를 바꾸면 기존 행성이 바뀌므로 새 값은 맨 뒤에서 뽑는다.
  - 소형: 진폭 4~9%, 중력 0.35~0.7(반지름에 비례). 중형: 진폭 1.2~2.5%, 촘촘한 굴곡, 중력 0.8~1.0.
- `HGPlanet::MakeApproachingPlanets(UniverseSeed, Cycle, Count)`: 주기별 시드 해시로 행성 목록. 첫째는 소형, 둘째는 중형이 나올 때까지 다시 뽑아 둘 다 고를 수 있게 보장한 뒤 이탈 시간순 정렬.
- 생물 군계별 색 `GroundColor`, `RockColor`.

### HGPlanetGenerator (.h/.cpp)
`L_PlanetSurface`에 하나 배치. 행성 중심 = 액터 위치.
- `ChoosePlanet()`: GameInstance의 `GetDivePlanet()`이 있으면 그것, 없으면(맵을 바로 열면) `PreviewPlanet`(`bPreviewFromSeedOnly`면 Seed만 쓰고 재생성). 시드로 노이즈 오프셋을 정한다.
- `SurfaceRadiusAt(Dir)`: 지형의 유일한 높이 함수. 5옥타브 fBm(Perlin3D), 생물 군계 보정(얼음 완만, 버섯숲 둔덕 강조), 북극 `LandingFlatRadius`(10m) 평탄화 후 2배 거리까지 부드럽게 복귀.
  - 들쭉날쭉함 `TerrainRuggedness`(기본 1, 0이면 큰 언덕만): 큰 언덕 위에 두 겹을 더 얹는다.
    - 능선: 큰 언덕보다 2.7배 촘촘한 3겹 ridged noise(`(1 - |노이즈|)²`, 평균을 빼서 행성이 부풀지 않게). 세기 얼음 0.4, 버섯숲 0.5, 바위 0.7.
    - 잔 굴곡: 약 9m 폭 2겹 fBm, 높이 얼음 45cm, 버섯숲 70cm, 바위 80cm (cm 고정이라 행성 크기와 상관없다). 중형 행성처럼 격자가 크면 폭을 격자 4칸 이상으로 늘리고 높이도 같은 비율로 키운다.
  - 착륙 지점 평탄화는 세 겹 모두에 적용된다. 확인 (작은 행성 셋, 재료 옆으로 이동해 캡처): 바위 행성은 능선과 둔덕이 뚜렷, 버섯숲은 굴곡진 언덕, 얼음은 잔 둔덕. 생성 155 ~ 474ms.
- `BuildTerrain()`: 큐브스피어. 면당 격자 = 반지름 * pi/2 / `TargetEdgeLength`(150), 상한 `MaxGridPerFace`(128).
  - 정육면체 점 → 구 사상(Nowell 식)으로 격자 크기를 고르게.
  - 법선은 접선 두 방향 유한 차분으로 계산 (면 이음매 명암 없음).
  - 삼각형 감기 순서는 면마다 첫 칸을 계산해 바깥을 향하도록 자동 결정 (`(P1-P2)x(P0-P2)`).
  - `UProceduralMeshComponent`, 복합 충돌 = 단순 충돌, 동기 쿠킹(사장님이 떨어지지 않게).
- `ScatterProps()`: 지형과 다른 시드 수열. 표면적 비례 개수 (바위 2000m²당 1, 20~1500 / 재료 표식 1750m²당 1, 24~800) × Richness. 착륙 지점 근처 제외. 바위는 인스턴스 메시(`RoundRocks`, `BlockRocks`, 충돌 있음).
- 재료 표식 (데이터 기반)
  - 재료 종류는 GameInstance의 재료 DataTable(`DT_Ingredients`) 행 순서다. 종류마다 `MarkerMesh`(구) 인스턴스 메시를 실행 중에 만들어 행의 `Color`로 칠한다 (충돌 없음).
  - 표식의 절반은 이 행성 군계가 `HomeBiome`인 재료, 나머지는 모든 재료에서 고르게. 크기 `MarkerScale` 0.4, 지표 위 22.
  - 표식 번호 = 생성 순서. 같은 시드면 같은 번호에 같은 재료와 자리가 나온다. 이미 캔 번호(`GI->IsMarkerHarvested(시드, 번호)`)는 처음부터 숨긴다(`bHarvested`).
  - 낮/밤 재료: 시간대와 상관없이 모든 표식을 같은 순서로 만들고, 재료의 `AvailableAt`이 지금 시간대(`GI->GetDayPhase()`, 다이빙한 시간대)가 아닌 표식을 숨긴다(`bOtherTime`). 그래서 한 행성에 낮 재료 자리와 밤 재료 자리가 따로 있다.
    시간대에 따라 재료를 다르게 뽑지 않는 이유: 같은 번호가 낮과 밤에 다른 재료를 가리키면 캔 기록(번호)이 꼬인다. 한 시간대에 약 절반만 보이므로 표식 수를 예전의 두 배로 만든다.
  - `FHGIngredientMarker::IsAvailable()` = 캐지 않았고 지금 시간대 재료. 찾기, 캐기, 남은 수, 미니맵이 모두 이것을 쓴다.
  - 채집 API: `FindNearestIngredient(From, MaxDistance)`, `GetMarkerIngredient`, `GetMarkerLocation`, `HarvestIngredient`(숨기고 GI에 기록, 재료 ID 반환), `GetRemainingIngredientCount`(지금 캘 수 있는 수).
  - 로그: "행성 배치 (밤): 바위 37, 재료 42 (종류 6, 다른 시간대 재료 22개 숨김, 이미 캔 것 1개 숨김, 지금 캘 수 있는 것 19)".
  - 숨기기(`HideInstance`)는 인스턴스 크기를 0으로 바꾼다. 인스턴스를 지우면 뒤 번호가 당겨져 다른 표식의 번호가 틀어지기 때문이다.
  - DataTable이 없으면 재료 없이 바위만 놓고 에러 로그를 남긴다.
- 표시용 조회 (미니맵): `GetIngredientMarkers()`(전체 표식, 캔 것 포함), `GetIngredientColor(Kind)`, `GetReturnPadLocation(Out)`(발판을 만들 때 위치를 기억해 둔다).
- `SpawnReturnPad()`: 착륙 지점에서 4m 옆에 금색 `AHGTravelPad`를 지연 생성 (`ReturnLevel`, `ReturnArrivalTag` 기본 `FromPlanet`, `ReturnName`).
- `GetLandingTransform()`: 북극 지표 + 95. `GetGravityCenter()`: 액터 위치.

### 행성 그림체 (`hg.PlanetMood`, 기본 1)
- 모양은 복셀, 색과 하늘은 노 맨즈 스카이(NMS)에서 배운다 (`Docs/Project/Design.md` "그림체"). 0으로 끄면 다음에 만드는 행성을 예전 매끈한 단색 모습으로 만든다 (비교용).
- 군계마다 팔레트(`FMoodPalette`): 땅 두 색, 바위, 하늘 꼭대기/지평선, 풀 두 색, 꽃 두 색, 덤불, 나무 줄기/잎. 얼음 = 청록 땅 + 분홍빛 라벤더 하늘, 버섯숲 = 보라 땅 + 청록 하늘, 바위 = 주황 땅 + 하늘색 하늘.
- 지형 (`BuildTerrain`): 정점을 삼각형마다 따로 두고 면 법선을 써서 각지게(로우폴리) 그린다. 면마다 노이즈 얼룩 + 높이 + 밝기 흔들기로 색을 정해 버텍스 컬러로 넣고 `M_HG_VertexColor`로 그린다.
- 하늘 돔: 엔진 구를 `SkyDomeRadius`(3km)로 키워 행성을 감싸고 `M_HG_PlanetSky` 동적 인스턴스(Center, Zenith, Horizon, SunDir, Brightness = `SkyBrightness` 3)를 입힌다. 해 색과 보조광 색도 팔레트에 맞춘다.
- 하늘빛 간접광: 실시간 캡처 스카이 라이트(`SkyLightIntensity` 1)를 놓는다. 하늘 머티리얼이 하늘(Is Sky)이라 돔 색이 그늘에 비친다. 이게 없을 때 구름 아래와 바위섬 밑이 검게 보였다.
- 복셀 (`ApplyMoodPreview`, 모양의 겉 칸만 채우는 `FillShell`):
  - 바위: 매끈한 바위를 숨기고(충돌 유지) 15cm 복셀 껍질로 다시 그린다.
  - 나무(20cm): 얼음 = 수정 기둥(줄기색 → 잎색 4단계), 버섯숲 = 큰 버섯, 바위 = 자홍색 4단 침엽수. 착륙 지점 둘레 14그루 + 넓이 900m²당 1그루.
  - 풀과 꽃: 착륙 지점 25m 안 1m²당 3포기, 25 ~ 45m 1m²당 1포기, 나머지 10m²당 1포기 (그림만, 충돌 없음).
- 구름: 기본 없음 (`bSkyClouds` 끔, 사용자 의견: 우주의 작은 행성에 구름이 있으면 어색하다). 켜면 고도 45 ~ 70m에 각진 구름(`SkyClouds` 절차적 메시: 낮은 해상도 구 덩어리 3 ~ 5개를 겹치고 밑면을 납작하게, `M_HG_Glow`로 살짝 스스로 빛남 `CloudGlow` 0.6, 그림자 없음).
- 떠 있는 바위섬 9개 (고도 18 ~ 40m): 복셀이 아니라 땅과 같은 각진 메시(`SkyIslands` 절차적 메시 하나, `M_HG_VertexColor`, 충돌 없음).
  - 모양: 8 ~ 11각 고리 여섯 겹. 윗면(가운데 둘레 + 가장자리)은 살짝 솟고, 가장자리 밑 흙 띠, 그 아래 세 겹이 좁아지고 비틀리며 뾰족한 끝으로 모인다. 꼭짓점마다 반지름과 높이를 흔든다.
  - 색: 윗면은 땅 두 색, 흙 띠는 땅색 0.7배, 바위는 끝으로 갈수록 어둡게. 면마다 밝기 흔들기.
  - 섬 모양은 섬 번호로 만든 따로 수열에서 뽑아서 구름 자리는 그대로다. 섬 하나 약 110 삼각형.
- 시험: `HGDive <번호>` (끄고 비교: `HGSeq hg.PlanetMood 0|HGDive <번호>`). 측정 (작은 행성 셋): 복셀 인스턴스 18만 ~ 39만 개, 색 묶음 32 ~ 38개, 생성 140 ~ 400ms.

## 흐름 / 규칙

- 저장해야 할 것은 시드와 플레이어가 바꾼 것(캔 자원 등)뿐이다.
- 높이를 쓰는 모든 곳(메시, 배치, 착륙, 발판)은 `SurfaceRadiusAt` 하나를 쓴다.
- 측정값 (스모크 테스트): 소형 반지름 51m 지형 정점 1.8만, 생성 50ms. 중형 반지름 409m 정점 10만 / 삼각형 19.7만, 생성 233ms.

## 알려진 문제와 다음 할 일

- 에디터 뷰포트에서는 지형이 보이지 않는다 (실행할 때만 생성). 에디터 미리보기가 필요하면 별도 버튼으로 만든다.
- 재료 배치 방식을 데이터 기반으로 바꾸면서, 그리고 낮/밤 재료를 넣으면서(표식 수 두 배, 재료 6종) 같은 시드의 재료 종류/자리가 이전 버전과 달라졌다 (지형과 바위는 그대로).
- 확인됨 (낮/밤, 반지름 72m 얼음 행성 시드 265933003): 낮 다이빙 재료 42개 중 23개 보임, 서리다시마 캠. 같은 행성에 밤 다이빙 → 19개 보임(낮 22 + 캔 1 숨김), 달빛연근 캠.
- 행성 조명은 시간대와 상관없이 같다. 밤 다이빙이면 하늘을 어둡게 하는 연출이 있으면 좋다.
- 캔 재료 기록은 게임이 켜져 있는 동안만 남는다 (저장 파일 없음).
- 밤 쪽이 꽤 어둡다 (보조광 1.2). 하늘에 별 없음.
- 중형 행성은 격자 상한 때문에 격자 한 칸이 약 5m로 거칠다. 더 크게 하려면 LOD/청크 분할이 필요하다.
- 다이빙 연출, 정거장 창밖 행성 표시는 아직 없다.
- 그림체: 떠 있는 바위섬 밑면은 여전히 어두운 편이다 (해가 위에서만 비춘다). 복셀 나무/풀은 충돌이 없어서 통과해 걷는다. 큰 행성은 복셀 인스턴스가 많아질 수 있어 거리별 줄이기(LOD)가 필요할 수 있다. 밤 다이빙이어도 하늘 돔은 낮 색이다.
