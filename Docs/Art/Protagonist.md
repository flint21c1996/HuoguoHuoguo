# Protagonist - 주인공 생김새 (Tripo 3D 생성용)

> 경로: `Docs/Art/` · 마지막 갱신: 2026-11-26

## 역할

주인공(은퇴한 복면 프로레슬러, 기획서 `Docs/Project/Design.md`의 "이야기")의 생김새와, Tripo에 넣을 레퍼런스 그림의 조건을 적은 문서다.
레퍼런스 그림을 Tripo에 넣어 3D 모델을 뽑고, 자동 리깅해서 게임에 넣는다. 지금 게임 안의 복셀 모습(`Docs/Source/Player.md`)은 옛 설정(직장인)의 자리 표시다.

## 그림 파일

- 그림 파일은 저장소에 두지 않는다 (사용자 결정 2026-11-26: GitHub 용량이 아깝다). 레퍼런스 그림은 저장소 밖에서 만들어 Tripo에 바로 넣는다.
- 2026-11-25 ~ 26 커밋(`f9a21dd`, `e6be8a1`)에 Claude가 벡터로 그린 그림(직장인판, 레슬러판)이 있었는데 지웠다. 사용자가 그림이 마음에 들지 않았고, 그림 생성 도구로 다시 뽑는 쪽이 낫다.

## Tripo 입력 그림의 조건 (자동 리깅이 잘 되게)

- 흰 배경, 한 장에 캐릭터 하나, 몸 전체가 다 들어간다. 앞/옆/뒤를 따로 넣을 때는 정면, 정측면, 정후면.
- A자세: 팔을 몸에서 비스듬히 아래로 벌린다 (수평에서 약 40도 아래). 팔과 몸통, 두 다리 사이가 떨어져 있어야 뼈대를 나누기 쉽다.
- 원근, 그림자, 소품 없음. 입을 다문 웃는 얼굴.
- 손은 엄지만 나뉜 벙어리장갑 모양이면 리깅이 단순하다 (손가락 뼈대가 필요하면 손가락을 그린다).
- 앞치마와 우주 헬멧은 그리지 않는다. 게임에서 켜고 끄는 소품이므로 몸과 따로 만든다.
- Tripo 여러 장 입력의 옆 칸이 "왼쪽/오른쪽"으로 나뉘어 있으면, 칸 이름이 카메라 위치 기준인지 캐릭터 기준인지 Tripo 화면의 예시 그림을 보고 맞춘다.

## 생김새

- 체격: 근육에 살집이 있는 천하장사 몸. 머리는 몸에 비해 작고, 목이 굵고, 어깨와 팔뚝이 넓다. 가슴과 배가 두툼하지만 배만 튀어나오지 않는다. 호감 가는 얼굴.
- 복면: 빨강 바탕, 이마에 금색 불꽃, 금테를 두른 흰 눈 둘레, 흰 입 둘레(웃는 입이 보임), 관자놀이에서 뒤로 가는 금색 줄, 뒤통수에 흰 끈(X자), 정수리 뒤 금색 띠.
- 옷: 남색 반팔 티셔츠(배와 등에 금색 원 안 빨간 불꽃), 흰 줄 남색 트레이닝 바지, 흰 운동화(빨간 밑창 줄), 손목 흰 테이핑.

## 알려진 문제와 다음 할 일

- 레퍼런스 그림이 아직 없다. 그림 생성 도구(GPT 이미지, Midjourney, Gemini, Tripo 자체 이미지 생성)로 위 조건과 생김새를 넣어 뽑는다.
- 복면 무늬, 옷 색, 불꽃 상징은 초안이다 (기획서 "이야기"에 초안으로 적어 둠).
- Tripo에서 뽑은 모델을 프로젝트에 넣는 방법(가져오기 설정, 크기, 사장님 캐릭터에 붙이는 코드)은 아직 없다.
