# Protagonist - 주인공 2D 레퍼런스 (Tripo 3D 생성용)

> 경로: `Docs/Art/Protagonist/` · 마지막 갱신: 2026-11-25

## 역할

주인공(은퇴한 복면 프로레슬러, 기획서 `Docs/Project/Design.md`의 "이야기")의 2D 레퍼런스 그림이다.
이 그림을 Tripo에 넣어 3D 모델을 뽑고, 자동 리깅해서 게임에 넣는다. 지금 게임 안의 복셀 모습(`Docs/Source/Player.md`)은 옛 설정(직장인)의 자리 표시다.

## 파일

| 파일 | 내용 | 용도 |
|---|---|---|
| `Protagonist_Front.png` | 앞모습 | Tripo 한 장 입력, 또는 여러 장 입력의 앞 |
| `Protagonist_Side_FacingLeft.png` | 옆모습, 화면 왼쪽을 봄 | 여러 장 입력의 옆 |
| `Protagonist_Side_FacingRight.png` | 옆모습, 화면 오른쪽을 봄 (위 그림을 좌우로 뒤집은 것) | 여러 장 입력의 반대쪽 옆 |
| `Protagonist_Back.png` | 뒷모습 | 여러 장 입력의 뒤 |
| `Protagonist_Sheet.png` | 앞, 옆, 뒤를 한 장에 모은 설정화 (글자 있음) | 사람이 보는 용도. Tripo에는 넣지 않는다 |
| `*.svg` | 위 PNG의 원본 벡터 그림 | 색이나 모양을 고칠 때 |

- PNG는 1024x1024, 흰 배경, 한 장에 캐릭터 하나, 몸 전체가 다 들어간다. 설정화만 2160x1100.
- Tripo 여러 장 입력의 옆 칸이 "왼쪽/오른쪽"으로 나뉘어 있으면, 칸 이름이 카메라 위치 기준인지 캐릭터 기준인지 Tripo 화면의 예시 그림을 보고 맞는 쪽을 넣는다. 두 방향 그림을 모두 두었다.
- 2026-11-25 이전 커밋의 같은 파일은 옛 설정(배불뚝이 직장인) 그림이다.

## 그림의 약속 (자동 리깅이 잘 되게)

- A자세: 팔을 몸에서 비스듬히 아래로 벌렸다 (수평에서 약 40도 아래). 팔과 몸통, 두 다리 사이가 떨어져 있어서 뼈대를 나누기 쉽다.
- 정면, 정측면, 정후면. 원근, 그림자, 소품 없음. 입을 다문 웃는 얼굴.
- 손은 엄지만 나뉜 벙어리장갑 모양이다 (손가락 뼈대가 필요 없을 때 리깅이 단순하다). 손가락이 필요하면 다시 그린다.
- 앞치마와 우주 헬멧은 그리지 않았다. 게임에서 켜고 끄는 소품이므로 몸과 따로 만든다.

## 생김새

- 체격: 근육에 살집이 있는 천하장사 몸. 머리는 몸에 비해 작고, 목이 굵고, 어깨와 팔뚝이 넓다. 가슴과 배가 두툼하지만 배만 튀어나오지 않는다. 키는 머리 약 4.6개.
- 복면: 빨강 바탕, 이마에 금색 불꽃, 금테를 두른 흰 눈 둘레, 흰 입 둘레(웃는 입이 보임), 관자놀이에서 뒤로 가는 금색 줄, 뒤통수에 흰 끈(X자), 정수리 뒤 금색 띠.
- 옷: 남색 반팔 티셔츠(배와 등에 금색 원 안 빨간 불꽃), 흰 줄 남색 트레이닝 바지, 흰 운동화(빨간 밑창 줄), 손목 흰 테이핑.
- 색: 피부 `#E8B48E`, 복면 `#C62F2B`, 금색 `#F2B632`, 흰 둘레 `#F6F1E7`, 옷 남색 `#2F3E66`(그늘 `#24304F`), 흰 줄과 운동화 `#F4F4F0`, 윤곽선 `#2B2420`.

## 알려진 문제와 다음 할 일

- Claude가 벡터로 그린 단순한 그림이다. Tripo 결과의 질감이 밋밋하면 이 그림을 바탕으로 그림 생성 도구나 사람이 더 칠한 그림을 쓴다.
- 복면 무늬, 옷 색, 불꽃 상징은 초안이다 (기획서 "이야기"에 초안으로 적어 둠).
- Tripo에서 뽑은 모델을 프로젝트에 넣는 방법(가져오기 설정, 크기, 사장님 캐릭터에 붙이는 코드)은 아직 없다.
